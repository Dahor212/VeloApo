# VeloTimer – upravená verze

Tato verze obsahuje:

- navigační boční menu,
- tlačítka zpět na detailu, tvorbě/editaci trasy, jízdě a výsledku,
- tapety v `/img/` a automatické pozadí podle obrazovky/trasy,
- výběr tapety při zakládání nebo editaci trasy,
- „TV grafiku“ jako live žebříček během jízdy,
- obrazovku celkových statistik s filtrem týden / měsíc / rok / celkem,
- upravený glassmorphism layout sladěný s cyklo tapetami,
- PWA manifest a ikonu aplikace.

## Nasazení na GitHub Pages

Nahraj do repository celý obsah této složky tak, aby `index.html`, `app.js`, `manifest.json` a složka `img` byly v kořeni webu.

Struktura:

```text
/index.html
/app.js
/manifest.json
/img/app-icon.webp
/img/wall1-sunset-mountain.webp
/img/wall2-blue-lake.webp
/img/wall3-lake-church.webp

/img/wall5-tuscany.webp

```
