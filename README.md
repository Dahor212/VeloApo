# VeloTimer v3

Cyklistický trenažér jako PWA aplikace.

## Struktura souborů

```
velotimer/
├── index.html      ← UI
├── app.js          ← logika
├── manifest.json   ← PWA manifest
└── img/            ← obrázky (pozadí + ikona)
    ├── app-icon.webp
    ├── wall1-sunset-mountain.webp
    ├── wall2-blue-lake.webp
    ├── wall3-lake-church.webp
    ├── wall4-bike-meadow.webp
    ├── wall5-tuscany.webp
    ├── wall6-bike-fence.webp
    ├── wall7-plains-road.webp
    └── wall8-alpine-snow.webp
```

## Nahrání na GitHub

Všech 12 souborů (3 v rootu + 9 v složce `img/`) je potřeba commitnout do repa.

Na GitHubu z mobilu:
1. otevři repo VeloApo v Safari
2. **Add file → Upload files**
3. vyber všechny soubory najednou (vč. složky img/)
4. Commit changes

GitHub Pages se automaticky obnoví do ~1 minuty.
